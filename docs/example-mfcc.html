MFCC Feature Extraction

Extract voice features without the engine. Feed into your own ML pipeline or analysis tool.

The Code

package main

import (
    "fmt"
    "os"
    "github.com/Aswanidev-vs/go-cognitive-voice/pkg/gcv"
)

func main() {
    path := os.Args[1]

    // Read audio
    samples, sampleRate, _ := gcv.ReadAudio(path)
    fmt.Printf("File: %s\nSample rate: %d Hz\nDuration: %.2fs\nSamples: %d\n\n",
        path, sampleRate, float64(len(samples))/float64(sampleRate), len(samples))

    // Extract MFCC features
    features := gcv.ExtractMFCC(samples, sampleRate)

    fmt.Printf("Feature frames: %d\n", len(features))
    fmt.Printf("Feature dimension: %d\n\n", len(features[0]))

    // Feature layout
    fmt.Println("Layout:")
    fmt.Println("  [0:14]  MFCC (13 coefficients + log energy)")
    fmt.Println("  [14:28] delta (1st derivative)")
    fmt.Println("  [28:42] delta-delta (2nd derivative)")

    // Show first 3 frames
    for i := 0; i < 3 && i < len(features); i++ {
        fmt.Printf("\nFrame %d: [", i)
        for j, v := range features[i] {
            if j > 0 { fmt.Print(", ") }
            fmt.Printf("%.2f", v)
        }
        fmt.Println("]")
    }
}

What Are MFCCs?

MFCCs (Mel-Frequency Cepstral Coefficients) are a compact representation of the spectral envelope of an audio signal. They capture the "shape" of the voice — what makes each speaker sound different.

Feature Layout

[0:14]13 MFCC coefficients + log energy. Captures spectral shape at each frame.
[14:28]Delta features. First derivative — how the spectrum changes over time.
[28:42]Delta-delta. Second derivative — acceleration of spectral change.
