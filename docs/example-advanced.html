Advanced: Persistence & Verification

Save/load speaker database, tune thresholds, verify specific speakers.

The Code

package main

import (
    "fmt"
    "os"
    "github.com/Aswanidev-vs/go-cognitive-voice/pkg/gcv"
)

const dbDir = "./speaker_db"

func main() {
    cfg := gcv.DefaultConfig()
    cfg.MatchThreshold = 0.85 // stricter matching

    engine := gcv.NewEngine(cfg)

    // Load existing database (if any)
    engine.LoadDatabase(dbDir)

    // Enroll speakers
    engine.EnrollSpeaker("alice", "Alice", []string{"alice.wav"})
    engine.EnrollSpeaker("bob", "Bob", []string{"bob.wav"})

    // Save for next run
    engine.SaveDatabase(dbDir)

    // Identify
    result, _ := engine.Identify("mystery.wav")
    fmt.Printf("%s (%.1f%%)\n", result.SpeakerName, result.Score*100)

    // Verify specific speaker
    matched, score, _ := engine.Detect("mystery.wav", "alice")
    fmt.Printf("Is Alice? %v (score: %.4f)\n", matched, score)

    // List all speakers
    for _, s := range engine.ListSpeakers() {
        fmt.Printf("  %s: %s (%d samples)\n", s.ID, s.Name, s.NumSamples)
    }
}

What's Different from Basic

PERSISTENCE

SaveDatabase / LoadDatabase

Saves enrolled speakers as JSON files. Load them on next startup without re-enrolling. Each speaker is one JSON file.

THRESHOLD

MatchThreshold = 0.85

Higher threshold = fewer false positives. Default is 0.5 (lenient). Use 0.7 for production, 0.85 for strict.

VERIFY

Detect (binary verification)

Detect(audio, speakerID) returns (matched, score, error). Use this when you know who you're looking for.

Threshold Guide

0.5Default. Lenient. Good for clean audio.
0.7Moderate. Recommended for production.
0.85Strict. Fewer false positives.
0.95Very strict. Almost no false positives.
