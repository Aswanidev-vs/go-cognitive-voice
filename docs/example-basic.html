Basic Speaker Identification

Enroll speakers, identify an unknown voice. 10 lines of code.

The Code

package main

import (
    "fmt"
    "os"
    "github.com/Aswanidev-vs/go-cognitive-voice/pkg/gcv"
)

func main() {
    // 1. Create engine with defaults
    engine := gcv.NewEngine(gcv.DefaultConfig())

    // 2. Enroll speakers
    engine.EnrollSpeaker("alice", "Alice", []string{
        "recordings/alice_01.wav",
        "recordings/alice_02.wav",
    })
    engine.EnrollSpeaker("bob", "Bob", []string{
        "recordings/bob_01.wav",
    })

    // 3. Identify an unknown voice
    result, err := engine.Identify("recordings/mystery.wav")
    if err != nil {
        fmt.Fprintln(os.Stderr, err)
        os.Exit(1)
    }

    if result.Identified {
        fmt.Printf("Speaker: %s (confidence: %.1f%%)\n",
            result.SpeakerName, result.Score*100)
    } else {
        fmt.Println("No matching speaker found.")
    }

    // 4. Show all candidates
    for _, m := range result.AllMatches {
        fmt.Printf("  %-10s score: %.4f\n", m.SpeakerName, m.Score)
    }
}

How It Works

STEP 1

Create the engine

NewEngine(DefaultConfig()) creates an engine with default settings. Uses centroid matching, 0.5 threshold, 13 MFCC coefficients.

STEP 2

Enroll speakers

Call EnrollSpeaker for each person. Provide 1+ audio files per speaker. More files = better accuracy. Supported formats: WAV, MP3.

STEP 3

Identify

Identify("mystery.wav") extracts MFCC features from the audio, compares against all enrolled speakers, and returns the best match.

STEP 4

Read results

result.Identified is true when the top score exceeds the threshold. result.AllMatches has all candidates ranked by score.

Run It

$ go run examples/basic/main.go

Output

Speaker: Alice (confidence: 88.1%)

All matches:
  Alice      score: 0.8806
  Bob        score: 0.6515

Key Concepts

EnrollSpeaker(id, name, files)Register a speaker. ID must be unique. Re-enrolling same ID replaces the old model.
Identify(audioPath)Find who's talking. Returns best match + all candidates.
result.IdentifiedTrue when top score >= MatchThreshold (default 0.5).
result.ScoreConfidence score 0.0–1.0. Higher = better match.

Tip: Use 2-5 audio files per speaker for best accuracy. Each file should be 1-10 seconds of clear speech.
