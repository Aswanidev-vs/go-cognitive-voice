Pure Go speaker identification

Feed it audio files. It tells you who's talking. No Python, no CGo, no ML frameworks.

$ go get github.com/Aswanidev-vs/go-cognitive-voice
01

Installation

go get github.com/Aswanidev-vs/go-cognitive-voice

Two dependencies, both pure Go:

gopxl/beepAudio decoding (WAV + MP3)
gonumFFT, matrix math
02

Quick Start

package main

import (
    "fmt"
    "github.com/Aswanidev-vs/go-cognitive-voice/pkg/gcv"
)

func main() {
    engine := gcv.NewEngine(gcv.DefaultConfig())

    // Register speakers
    engine.EnrollSpeaker("alice", "Alice", []string{
        "alice_01.wav",
        "alice_02.wav",
    })

    // Identify who's talking
    result, _ := engine.Identify("mystery.wav")
    if result.Identified {
        fmt.Printf("%s is talking (%.0f%%)\n",
            result.SpeakerName, result.Score*100)
    }
}

10 lines. Done.

04

Engine

The engine is the core object. Create one, enroll speakers, then identify or detect.

engine := gcv.NewEngine(gcv.DefaultConfig())

Defaults work for most cases. See Configuration to tune.

05

Enroll

Register a speaker from one or more audio files. More files = better accuracy.

err := engine.EnrollSpeaker(
    "alice",    // unique ID
    "Alice",    // display name
    []string{"alice_01.wav", "alice_02.wav"},
)

Re-enrolling the same ID replaces the old model. It does not merge.

Formats: WAV (PCM 8/16/24/32-bit, float32/64), MP3.

06

Identify

Find who's talking. Returns the best match and all scored candidates.

result, err := engine.Identify("mystery.wav")

if result.Identified {
    fmt.Printf("%s (%.1f%%)\n",
        result.SpeakerName, result.Score*100)
}

// All candidates, ranked
for _, m := range result.AllMatches {
    fmt.Printf("  %s: %.4f\n", m.SpeakerName, m.Score)
}

result.Identified is true when the top score exceeds MatchThreshold.

07

Detect

Verify if audio matches a specific speaker. Binary yes/no with confidence score.

matched, score, err := engine.Detect("audio.wav", "alice")

if matched {
    fmt.Printf("Confirmed: Alice (%.1f%%)\n", score*100)
}
08

Persistence

Save enrolled speakers to disk. Load them back on next startup.

// Save
engine.SaveDatabase("./speaker_db")

// Load
engine.LoadDatabase("./speaker_db")

Each speaker is stored as a JSON file. The directory is created automatically.

Configuration

cfg := gcv.DefaultConfig()
cfg.MatchThreshold = 0.85  // stricter matching
cfg.TrainMethod = "centroid"

engine := gcv.NewEngine(cfg)

Threshold guide:

0.5Lenient. Default. Good for clean audio.
0.7Moderate. Recommended for real-world use.
0.85Strict. Fewer false positives.
0.95Very strict. Almost no false positives.

How It Works

The full pipeline from audio file to speaker identity:

Audio Decoder
WAV/MP3 to mono float64 samples
gopxl/beep
Pre-emphasis + Framing
High-pass filter, 25ms frames, 10ms hop, Hamming window
FFT + Power Spectrum
Cooley-Tukey radix-2 FFT, squared magnitude
Mel Filter Bank + Log
26 triangular filters, log energy
DCT + Deltas
13 MFCC + 13 delta + 13 delta-delta = 42 features
Speaker Model
Centroid, GMM, or DTW matching
Cosine + Mahalanobis
Score against enrolled speakers

<0.5

Feature Extraction

Extract MFCC features without the engine. Useful for custom pipelines.

// From file
features, _ := engine.ExtractFeatures("audio.wav")

// From raw samples
features := gcv.ExtractMFCC(samples, sampleRate)

// features: [][]float64 — [numFrames][42]
//   [0:14]  MFCC (13 coefficients + log energy)
//   [14:28] delta (1st derivative)
//   [28:42] delta-delta (2nd derivative)
15

Streaming

For live microphone, websocket, or chunked file input. Push samples as they arrive, identify in fixed-size chunks.

engine := gcv.NewEngine(gcv.DefaultConfig())
engine.EnrollSpeaker("alice", "Alice", []string{"alice.wav"})

// Identify every 1 second
buf := engine.NewStreamBuffer(16000, 1.0)

// Push chunks from mic/websocket/file
for chunk := range audioChan {
    buf.Write(chunk)

    if result, ok := buf.Identify(); ok {
        fmt.Printf("%s (%.1f%%)\n",
            result.SpeakerName, result.Score*100)
    }
}

// Final ID on all accumulated audio
result := buf.IdentifyFull()
MethodWhen to use
Write(samples)Push audio chunks from mic/websocket/file
Identify()Runs when enough audio accumulated
IdentifyFull()Use at stream end for final ID
Reset()Clear buffer between speakers
Duration()Check buffered audio duration

vs Python Alternatives

Honest comparison with popular Python speaker identification libraries.

GCV (this)speechbrainresemblyzerpyannote
LanguageGoPythonPythonPython
AlgorithmMFCC + centroid/GMMECAPA-TDNN (neural)d-vector (neural)PyanNet (neural)
Accuracy~80-90%~95-98%~90-95%~93-97%
Dependencies2 packagesPyTorch + 10+PyTorch + 5+PyTorch + 8+
Install size~10 MB~2 GB+~2 GB+~2 GB+
StreamingYesYesNoYes
DiarizationNoYesNoYes

When to use GCV: Go service with no Python runtime, minimal dependencies, ~80-90% accuracy is acceptable, lightweight embedded solution.

When to use Python: Maximum accuracy needed, noisy real-world audio, speaker diarization, ML research pipeline.

The accuracy gap exists because Python libraries use deep neural networks trained on thousands of hours of speech. GCV uses traditional DSP (MFCC + statistical models). GCV works well for clean, controlled audio with distinct speakers.
