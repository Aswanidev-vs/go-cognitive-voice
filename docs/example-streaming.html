Streaming Audio

Real-time speaker identification from chunked audio. Works with microphone, websocket, or file streams.

The Code

package main

import (
    "fmt"
    "os"
    "github.com/Aswanidev-vs/go-cognitive-voice/pkg/gcv"
)

func main() {
    path := os.Args[1]
    sampleRate := 16000
    chunkSize := sampleRate / 4 // 250ms chunks

    // Load audio (in real usage, read from mic/websocket)
    samples, sr, _ := gcv.ReadAudio(path)
    if sr != sampleRate { sampleRate = sr; chunkSize = sampleRate / 4 }

    engine := gcv.NewEngine(gcv.DefaultConfig())

    // Create streaming buffer — identify every 1 second
    buf := engine.NewStreamBuffer(sampleRate, 1.0)

    // Push chunks
    for i := 0; i < len(samples); i += chunkSize {
        end := i + chunkSize
        if end > len(samples) { end = len(samples) }
        buf.Write(samples[i:end])

        if result, ok := buf.Identify(); ok {
            fmt.Printf("[%.1fs] %s (score: %.3f)\n",
                buf.Duration()-1.0, result.SpeakerName, result.Score)
        }
    }

    // Final ID on full audio
    result := buf.IdentifyFull()
    fmt.Printf("Final: %s (%.3f)\n", result.SpeakerName, result.Score)
}

How It Works

STEP 1

Create StreamBuffer

NewStreamBuffer(engine, 16000, 1.0) creates a buffer that identifies every 1 second of accumulated audio. Adjust the chunk size for your use case.

STEP 2

Push chunks with Write()

Feed audio chunks from any source: microphone, websocket, file reader. Chunks can be any size — the buffer handles accumulation.

STEP 3

Call Identify() after each chunk

Identify() returns (result, true) when enough audio has accumulated, or (nil, false) otherwise. Non-blocking.

STEP 4

Final ID with IdentifyFull()

At stream end, call IdentifyFull() for a final identification on ALL accumulated audio.

API Reference

NewStreamBuffer(engine, sampleRate, chunkSec)Create buffer. chunkSec=1.0 means identify every second.
Write(samples)Push audio chunk. Mono float64, [-1, 1].
Identify()Returns (result, true) when chunk ready, (nil, false) otherwise.
IdentifyFull()Final ID on all accumulated audio.
Reset()Clear buffer between speakers.
Duration()How much audio is buffered (seconds).
