Neural Network + i-vector

Enable the custom neural network and PLDA scoring for ~85-93% accuracy. Trains from scratch — no pre-trained models.

The Code

package main

import (
    "fmt"
    "github.com/Aswanidev-vs/go-cognitive-voice/pkg/gcv"
)

func main() {
    cfg := gcv.DefaultConfig()

    // Enable advanced features
    cfg.UseNeural = true     // custom neural network
    cfg.UseIVector = true    // i-vector + PLDA scoring
    cfg.UseRASTA = true      // noise-robust features
    cfg.UseVAD = true        // voice activity detection
    cfg.MatchThreshold = 0.7

    engine := gcv.NewEngine(cfg)

    // Training happens automatically inside EnrollSpeaker.
    // Provide audio files, the network learns from them.
    engine.EnrollSpeaker("alice", "Alice", []string{
        "alice_01.wav",
        "alice_02.wav",
        "alice_03.wav",
    })
    engine.EnrollSpeaker("bob", "Bob", []string{
        "bob_01.wav",
        "bob_02.wav",
    })

    // Identify — uses the trained neural network
    result, _ := engine.Identify("mystery.wav")
    fmt.Printf("%s (%.1f%%)\n", result.SpeakerName, result.Score*100)
}

What Happens Under the Hood

You never call Train(). When you call EnrollSpeaker with UseNeural: true, the engine automatically:

1. Extract MFCCFeatures from your audio files
2. Train neural netContrastive learning on all speakers' features
3. Train i-vectorGMM-UBM + total variability matrix
4. Train PLDAProbabilistic LDA for scoring
5. Compute embeddingsNeural embeddings + i-vectors for each speaker

When to Enable What

UseNeuralEnable when you have 2+ speakers with 2+ audio files each. Improves accuracy from ~80% to ~85-90%.
UseIVectorEnable for best accuracy. Adds ~85-93% when combined with neural. Slower training.
UseRASTAEnable for noisy environments. Removes channel variation and fast noise.
UseVADEnable when audio has silence or background noise. Filters out non-speech frames.

Accuracy Comparison

Default (centroid)~80-85%Fast, no training
+ Neural~85-90%Auto-trains on enrollment
+ Neural + i-vector~85-93%Best accuracy, slower
+ RASTA + VAD+2-5% in noiseRobust to real-world audio

Key insight: All training happens from your enrollment data. No pre-trained models, no downloads, no PyTorch. The network learns to distinguish YOUR speakers from YOUR audio.
